# ICP 备案资料清单（Dreikanterbot 自托管）

> 说明：本文件是准备清单，不是备案成功证明。ICP 备案必须由**域名持有主体**通过**境内接入商**提交，
> 需要真实证件与人脸/短信核验；代码仓库不能代替备案，也不能伪造备案号。

## 1. 先判断是否需要备案

| 部署方式 | 是否需要 ICP |
|---|---|
| 中国大陆境内服务器 + 域名访问 | 需要（未备案域名可能被接入商拦截 80/443） |
| 香港/海外服务器 + 域名 | 通常不需要 ICP，但需遵守当地法律与平台规则 |
| 仅内网 / localhost / 本机客户端 | 不需要 ICP |

## 2. 需要准备的主体资料

- 主体类型：企业 / 个体工商户 / 个人
- 企业：营业执照、法定代表人身份证、主体负责人身份证、网站负责人身份证
- 个人：身份证正反面、本人手机号、邮箱
- 域名：已实名认证，域名持有者与备案主体一致
- 境内服务器：接入商（阿里云/腾讯云/华为云等）的备案服务号或实例
- 网站名称、服务内容、预计上线时间
- 负责人手机号（用于短信核验）与应急联系方式
- 部分省份要求：前置审批（新闻/出版/教育/医疗等）、承诺书、核验单

## 3. 提交路径

1. 在接入商控制台进入「ICP 备案」；
2. 选择主体与域名，填写网站信息；
3. 上传证件、完成人脸核验/短信核验；
4. 接入商初审 → 管局审核（通常 1–20 个工作日）；
5. 通过后获得 `京ICP备XXXXXXXX号-1` 形式的备案号；
6. 将备案号放在网站页脚，并链接到 `https://beian.miit.gov.cn/`。

## 4. 本站需要填写的位置

- 前端页脚：`frontend/src/components/...`（当前版本未写死备案号，避免伪造）
- 上线前请把真实备案号加入登录页/设置页页脚，并保留可点击的工信部链接。
- 若使用公安联网备案，还需在页脚加入公安备案号与链接。

## 5. 与 Dreikanterbot 相关的合规注意

- **生成式 AI 服务**：面向公众提供生成式 AI 服务，可能涉及《生成式人工智能服务管理暂行办法》等要求；
  自用/内部团队使用与公开运营的合规义务不同，公开运营前请咨询专业合规人员。
- **用户模型 Key**：V3 默认 BYOK，平台不代收模型费用；仍需在隐私政策中说明 Key 的加密存储方式。
- **记忆库文件**：可能包含个人信息/商业秘密；需要提供删除、导出能力（已实现）并限制管理员访问。
- **日志**：不要记录用户 API Key、完整对话内容或上传文件正文；当前后端只记录调用元数据。
- **数据出境**：若调用境外模型 API，需评估数据出境与个人信息保护要求。
