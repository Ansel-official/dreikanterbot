Dreikanterbot 隐私政策

开发者　Ansel Design（Apsis severs）
版本　3.1.1　　生效日期　2026-11-26
形态　可自托管的全栈应用（后端 + 网页前端 + Windows/Android 客户端）
联系邮箱　Anselyoyo@outlook.com
一句话：你自己的模型，你自己的数据。
Dreikanterbot 可以跑在你自己的服务器或电脑上。账号、API Key（加密存储）、记忆库都在你自己的数据库里； 我们不做数据买卖、不投广告、不接第三方统计 SDK。

一、谁在处理你的数据

  • 自己部署自己用（推荐）：所有数据都在你的机器上，开发者无法访问。
  • 使用他人搭建的实例：实例运营者能看到你提交的内容，请以该运营方公布的政策为准。

二、收集哪些数据（仅限提供服务所必需）

类别具体内容用途存储
账号用户名、密码（加盐哈希存储，不存明文）登录与权限你的数据库 users
模型配置你填写的大模型 API Key、BaseURL、默认模型代你调用所选的模型厂商user_ai_settings，Key 字段加密存储（api_key_encrypted）
对话消息内容、会话标题、分支多轮对话与续聊按实例配置存数据库或本地
记忆库你主动让 AI 记住的条目跨会话长期记忆memory_items
用量token 计数、预算消耗预算控制与展示你的数据库
插件配置WebDAV 等外部服务的账号密码（启用时才填）同步/备份密码字段加密存储（password_encrypted）

我们不收集：设备标识符、位置、通讯录、相册、剪贴板、应用使用行为埋点。

三、数据流向

  1. 客户端（网页 / Windows / Android）→ 你的后端；
  2. 后端用**你配置的 Key** 调用你选择的模型厂商（DeepSeek、Moonshot/Kimi 等），把本轮对话上下文发过去；
  3. 模型返回后存库并回传客户端。

除此之外没有第三方数据出口。若你启用 WebDAV 同步或插件，数据只发往你自己填写的地址。

⚠️ 调用云端模型时，对话内容会按该厂商的隐私政策处理。处理敏感信息时请自行评估，或改用自有/本地模型端点。

四、密钥与凭证如何保护

  • 用户密码：加盐哈希，不可逆；
  • 模型 API Key、WebDAV 密码：加密后入库，接口不回传明文，前端只显示「已配置」；
  • 卸载/删除实例时，直接删除数据库文件即可彻底清除。

五、你的权利

权利怎么做
查看设置页可见账号信息、模型配置摘要、记忆条目、token 用量
更正设置页直接改；用户名/密码在账号设置里修改
删除删除单条对话 / 单条记忆；删除账号（管理员 cli.py 支持删除用户）；清库即全部清除
导出对话与记忆可导出；数据在你自己的库里，可直接备份

六、共享与跨境

我们不出售、不共享你的数据。由于软件自托管，数据存放位置由部署者决定； 若你把实例部署在境外服务器，即构成数据的跨境存储，请自行确认合规。

七、儿童

不面向 14 周岁以下儿童单独设计，也不主动收集儿童个人信息。

八、安全提示

  • 请修改默认管理员口令，启用 HTTPS；
  • 不要把 .env、数据库文件提交到公开仓库；
  • 多用户实例请按需分配权限，定期备份。

九、政策变更

功能涉及数据处理方式变化时（例如新增云端同步、第三方登录），会先更新本政策并在应用内提示。

English Summary

Dreikanterbot is a self-hostable, full-stack AI workspace. Accounts, encrypted API keys, conversations and memories are stored in your own database. Passwords are salted-hashed; provider keys and WebDAV passwords are stored encrypted. The app sends requests only to the model providers you configure and to endpoints you enter yourself. No analytics, no ads, no data selling.
